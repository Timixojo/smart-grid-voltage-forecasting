# Forecasting Voltage Fluctuations in Smart Grids Using a CNN–Transformer Hybrid Model

This project forecasts short-term voltage fluctuations in a multi-node smart grid using a hybrid Convolutional Neural Network (CNN) and Transformer model.

## Objectives

- Forecast short-term voltage fluctuations in a multi-node smart grid.
- Develop a hybrid CNN–Transformer model for time-series forecasting.
- Compare the proposed model with baseline forecasting approaches.
- Evaluate forecasting performance using standard regression metrics.
- Investigate the impact of different model configurations through sensitivity analysis.

## Dataset

This project uses the **SoCal28Bus Digital Twin Dataset**.

The original dataset is **not included** in this repository because it was obtained under restricted academic access.

Generated evaluation outputs included in this repository were produced from the original research dataset.
